# The three challenges

These are based on real challenges from the Scottish Government's [CivTech programme](https://www.civtech.scot/civtech-12-challenges) (round 12). **We aren't entering CivTech.** We're using the challenges to learn. Each sheet has the same sections, so every squad gets the same picture.

| # | Challenge | Based on |
|---|---|---|
| 1 | [Healthier homes: finding tenants at risk before they get ill](challenge-1-healthier-homes.md) | CivTech 12.6 |
| 2 | [Help when it's needed: connecting people affected by substance use with support out of hours](challenge-2-help-when-its-needed.md) | CivTech 12.1 |
| 3 | [Proving circular pays: making the business case for the circular economy](challenge-3-proving-circular-pays.md) | CivTech 12.3 |

- Any squad can take any challenge, whatever its mix of professions, and several squads can pick the same one.
- Read them whenever you like before the day, and ask Claude about them (`/challenges`). Choosing one is for the day.
- Want to know more? `/find-out`. The CivTech pages have the full detail, and Claude may come across them when it researches.

Every sheet ends the same way: **decide whose problem you'll tackle, then build as much of it as you can.**
