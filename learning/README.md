# Learning

One log per person in `people/`, so two people never edit the same file. `/start-here` creates yours, `/reflect` adds to it. The questions are in `questions.md`: everyone gets the same clickable options, and each answer is stored as a code in the log's front matter, so the answers can be counted across squads.

What we're learning about, as a squad and as Mercator:

- How much people can do beyond their job title when everyone builds with Claude.
- What makes building as a squad with AI easy or hard.
- Where the tooling helps, where it gets in the way, and where it surprises us.

Prompts are copied word for word. The logs, plus the git history, feed the fuller showcase after the day.
